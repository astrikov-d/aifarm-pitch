# AI Farm pitch

Статическая HTML-презентация бизнес-идеи AI Farm.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер:

```bash
python3 -m http.server 8080
```

Управление: стрелки, Page Up / Page Down, пробел. Кнопка в правом верхнем углу включает полноэкранный режим.

## GitHub Pages

В настройках репозитория выберите **Pages → Deploy from a branch → main / root**. Презентация не требует сборки.
